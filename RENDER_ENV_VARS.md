# Render Environment Variables Configuration

This document lists all environment variables required for deploying AgroScan NG to Render.com.

## Backend API Service (agroscan-api)

### Required Variables
- `DATABASE_URL` - PostgreSQL connection string (auto-generated from Render database)
  - Format: `postgresql://user:password@host:port/database`
  - Source: Render Database Service → Internal Database URL

- `INFERENCE_URL` - URL of the inference service
  - Value: `https://agroscan-inference.onrender.com` (if deploying inference service)
  - Alternative: External inference service URL

- `JWT_SECRET` - Secret key for JWT token generation
  - Value: Generate secure random string (32+ characters)
  - Example: `openssl rand -base64 32`

- `ALLOWED_ORIGINS` - CORS allowed origins for frontend
  - Value: `https://agroscan-frontend.onrender.com`
  - Multiple origins: comma-separated list

### Optional Variables
- `UPLOAD_DIR` - Directory for storing image thumbnails
  - Default: `/app/uploads/thumbnails`
  - Value: `/app/uploads/thumbnails`

- `UPLOAD_URL_PREFIX` - URL prefix for serving thumbnails
  - Default: `/api/v1/uploads/thumbnails`
  - Value: `/api/v1/uploads/thumbnails`

## Inference Service (agroscan-inference)

### Required Variables
- `MODEL_VERSION` - Version of the ML model to use
  - Value: `v1`
  - Available versions: `v1`, `v2`, `v3`, `v4`, `v5`

## Frontend Service (agroscan-frontend)

### Required Variables
- `VITE_API_BASE_URL` - Base URL for backend API
  - Value: `https://agroscan-api.onrender.com/api/v1`
  - Must include full URL with protocol

## Database Service (agroscan-db)

### Auto-Generated Variables
Render automatically generates these for PostgreSQL:
- `DATABASE_URL` - Internal connection string
- `PGHOST` - Database host
- `PGPORT` - Database port (5432)
- `PGUSER` - Database user
- `PGPASSWORD` - Database password
- `PGDATABASE` - Database name

## Setting Environment Variables in Render

### Via Dashboard
1. Go to your service in Render Dashboard
2. Click "Environment" tab
3. Add each variable with key-value pairs
4. Click "Save Changes"
5. Service will automatically restart

### Via Render CLI
```bash
render env set DATABASE_URL "postgresql://..."
render env set JWT_SECRET "your-secret-key"
render env set ALLOWED_ORIGINS "https://agroscan-frontend.onrender.com"
```

### Via Blueprint
Variables are defined in `render.yaml` under `envVars` section.

## Security Best Practices

### JWT Secret
- Use a cryptographically secure random string
- Minimum 32 characters recommended
- Don't commit to version control
- Rotate periodically

### Database Credentials
- Use Render's internal networking
- Never expose database port publicly
- Use strong passwords (auto-generated by Render)

### CORS Configuration
- Only allow trusted origins
- Use HTTPS only
- Be specific with allowed domains

## Testing Environment Variables

### Backend API
```bash
# Test locally with Render-like environment
export DATABASE_URL="postgresql://..."
export INFERENCE_URL="http://localhost:8502"
export JWT_SECRET="test-secret"
export ALLOWED_ORIGINS="http://localhost:5173"
python wsgi.py
```

### Inference Service
```bash
export MODEL_VERSION=v1
uvicorn serve:app --host 0.0.0.0 --port 8502
```

### Frontend
```bash
export VITE_API_BASE_URL="http://localhost:5002/api/v1"
npm run dev
```

## Troubleshooting

### Variables Not Loading
- Check service logs for variable loading errors
- Verify variable names match exactly (case-sensitive)
- Ensure no trailing spaces in values
- Restart service after adding variables

### Database Connection Issues
- Verify DATABASE_URL format
- Check database service is running
- Ensure both services are in same region
- Use internal networking (not public URLs)

### CORS Errors
- Verify ALLOWED_ORIGINS matches frontend URL exactly
- Include protocol (https://)
- No trailing slashes
- Multiple origins: comma-separated

## Production vs Development

### Development (Local)
```bash
DATABASE_URL=sqlite:///dev.db
INFERENCE_URL=http://localhost:8502
JWT_SECRET=devsecret
ALLOWED_ORIGINS=http://localhost:5173
VITE_API_BASE_URL=http://localhost:5002/api/v1
```

### Production (Render)
```bash
DATABASE_URL=postgresql://... (Render-generated)
INFERENCE_URL=https://agroscan-inference.onrender.com
JWT_SECRET=<secure-random-string>
ALLOWED_ORIGINS=https://agroscan-frontend.onrender.com
VITE_API_BASE_URL=https://agroscan-api.onrender.com/api/v1
```
