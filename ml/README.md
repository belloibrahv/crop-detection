# AgroScan NG — ML Training Guide

Complete walkthrough: data acquisition → preprocessing → training → evaluation → deployment.

---

## 1. Prerequisites

```bash
# Python 3.10+  (3.11 recommended)
pip install -r ml/requirements.txt
```

You also need a **Kaggle API token** for two of the five datasets.

1. Sign in at [kaggle.com](https://www.kaggle.com) → Settings → API → **Create New Token**
2. Place `kaggle.json` at `~/.kaggle/kaggle.json`
3. `chmod 600 ~/.kaggle/kaggle.json`

You also need to accept the competition rules for the Cassava dataset:
- Visit [Cassava Leaf Disease Classification](https://www.kaggle.com/competitions/cassava-leaf-disease-classification/data) and click **Join Competition**.

---

## 2. Dataset Sources

| # | Dataset | Classes covered | Size | Source |
|---|---------|-----------------|------|--------|
| 1 | **PlantVillage** | Tomato (8 diseases + healthy), Maize (3 diseases + healthy) | ~18 k tomato + ~3.8 k maize | Kaggle: `abdallahalidev/plantvillage-dataset` |
| 2 | **Kaggle Cassava 2020** | Cassava (4 diseases + healthy) | ~26 k | Kaggle competition: `cassava-leaf-disease-classification` |
| 3 | **CCMT** | Cassava + Maize + Tomato supplemental | ~24 k raw | [Mendeley bwh3zbpkpv](https://data.mendeley.com/datasets/bwh3zbpkpv/1) |
| 4 | **Rice Leaf Disease** | Rice Blast, Brown Spot, Bacterial Blight, Healthy | ~5 k | Kaggle: `minhhuy510/rice-leaf-diseases-dataset` |
| 5 | **Augmentation** | Yam (all 5 classes) + any class < 300 images | synthetic | Generated by `download_datasets.py` |

**Yam note:** No large public yam disease image dataset exists as of 2026. The script
augments whatever local images you place in `data/raw/Yam/<disease>/` to reach 300 images
per class. For best results, **collect 50–100 real yam leaf photos per class** from local
farms in Ogun State (as described in SRS §11.1) before training.

## 3. Download All Data

```bash
# From the repo root:
python ml/download_datasets.py --output data/raw
```

This will:
1. Download PlantVillage from Kaggle → copy Tomato + Maize images
2. Download Cassava 2020 from Kaggle → copy all 5 Cassava classes
3. Download Rice dataset from Kaggle → copy 4 Rice classes
4. Download CCMT from Mendeley → supplement Cassava/Maize/Tomato
5. Augment any class below 300 images (especially Yam)

## 4. Prepare Splits

```bash
python ml/data_prep.py \
  --data-dir  data/raw \
  --output-dir data/splits
```

Produces `data/splits/train.csv`, `val.csv`, `test.csv` (70/15/15 stratified split).

---

## 5. Train

### On a local GPU (recommended):
```bash
python ml/train.py \
  --train-csv  data/splits/train.csv \
  --val-csv    data/splits/val.csv \
  --output     inference/models/v1 \
  --epochs-phase1 20 \
  --epochs-phase2 20 \
  --batch-size 32 \
  --mixed-precision     # optional: 2× faster on NVIDIA GPUs
```

### On Google Colab (free T4 GPU):
Upload the repo to Google Drive and run the notebook at
`ml/notebooks/train_mobilenetv2.ipynb`. It handles Kaggle auth and mounts Drive automatically.

Training time estimates:
| Hardware | Phase 1 | Phase 2 | Total |
|----------|---------|---------|-------|
| NVIDIA T4 (Colab) | ~25 min | ~40 min | ~65 min |
| NVIDIA A100       | ~8 min  | ~12 min | ~20 min |
| MacBook M-series  | ~3–4 h  | ~5–6 h  | ~9 h   |

---

## 6. Evaluate (93% gate)

```bash
python ml/evaluate.py \
  --model-dir      inference/models/v1 \
  --test-csv       data/splits/test.csv \
  --class-indices  inference/models/v1/class_indices.json
```

Exit 0 = pass (≥93% weighted accuracy) → safe to promote to production.
Exit 1 = fail → do not deploy.

---

## 7. Deploy the New Model

```bash
# Copy the new class_indices.json to the inference container's expected path
cp inference/models/v1/class_indices.json inference/models/class_indices.json

# Rebuild and restart the inference container only
docker compose build inference
docker compose up -d inference
```

The `api` and `frontend` containers do not need to be touched.

---

## 8. Adding Real Yam Images

Until a public yam dataset becomes available:

1. Collect leaf photos from farms (minimum 50 per disease class).
2. Place them in the appropriate folder:
   ```
   data/raw/Yam/Yam Anthracnose/   ← your photos
   data/raw/Yam/Yam Mosaic Virus/
   data/raw/Yam/Yam Dry Rot/
   data/raw/Yam/Yam Leaf Spot/
   data/raw/Yam/Yam Healthy/
   ```
3. Re-run `download_datasets.py` — it will augment your real images to ≥300 per class.
4. Repeat steps 4–7 above.
